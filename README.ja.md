Cicada は、Zoom、Teams、Feishu の通話から、X スペース、Discord のステージ、YouTube のライブ配信まで、パソコンで再生されているあらゆるものに対応します。システムの音声を直接聞き取ることで、通話にボットを送り込んだり、ほかの人に何かをインストールしてもらったりすることなく、リアルタイムの二か国語の字幕と構造化された議事メモを提供します。自分が会話に加わりたいときは、話すキー（Mac は右の `⌥`、Windows は右の `Ctrl`）を押したまま話すだけで、翻訳された声を会議にそのまま届けられます。Mac では音声認識がパソコンの中で行われるので、音声が外に出ることはありません。

> この日本語版は [README.en.md](README.en.md) の翻訳です。内容が食い違う場合は英語版と中国語版が最新です。

## 対応プラットフォーム

| プラットフォーム | 動作環境 | 備考 |
|---|---|---|
| Mac | macOS 14.4 以降、Apple シリコン / Intel | すべての機能に対応。Apple シリコンは Mac の中で音声認識を行い（キーなしでも可）、Intel 版は Ling のキーが必要（Ming で音声認識） |
| Windows | Windows 10 2004 以降、x64 / ARM64 | Ling のキーが必要（使えない場合は OpenRouter、ZenMux なども可）。[windows/](windows/README.md) を参照 |
| Linux | Ubuntu 22.04 / 24.04 デスクトップ | Ling かほかの AI サービスのキーが必要。メモのウィンドウは画面共有に映ります。[linux/](linux/README.md) を参照 |
| Android | Android 10 以降 | Ling かほかの AI サービスのキーが必要。動画や配信の字幕、対面での通訳。[android/](android/README.md) を参照 |

> **AI サービス：** Mac では、メモと自然な音声に OpenRouter（推奨）、Ling、ZenMux、OpenAI が使えます（[設定する](#ling-api-key)）。Windows、Linux、Android 版でも同じサービスを使えます。こちらでは相手の音声の認識もそのサービスが行うため、字幕は Ling より 1〜2 秒遅れます。

4 つのプラットフォームは同じバージョン番号と同じ会議の記録の形式を共有しています。ダウンロードは[Web サイト](https://cicada.indaloop.app/ja/download/)と [Releases](https://github.com/wquguru/cicada/releases) から。以下の機能の説明は Mac 版のものです。

## 機能

### リアルタイムのメモと二か国語の書き起こし

会議の進行中、メモのウィンドウには、要約、トピックと要点、結論、ToDo、フィッシュボーン図、人名と用語の用語集が整理され、各結論や ToDo をクリックすると、二か国語の書き起こしの根拠となる行に直接戻れます。Cicada はメモ全体で人名と用語を統一し、誤って認識された表記を覚えているので、`⌘F` では正規の表記とその揺れの両方を検索できます。AI サービスにあなたにしか直せない問題（キー、残高、モデル）があるときは、メモのウィンドウが知らせ、メニューバーのアイコンにオレンジの点が付きます。マイクをオンにしたのにマイクが使えないときは、メモのウィンドウ、字幕バー、メニューバーのアイコンのすべてで知らせます。

### リアルタイムの字幕と言語の検出

Cicada は、話されている言語を数秒以内にデバイス上で検出してシステムの言語に翻訳し、`⌃⌥S` を押すと、メモのウィンドウ、コンパクトな字幕バー、非表示を切り替えられます。字幕バーは誰かが話しているときにだけ表示され、ポインターを重ねると透けるので、その下をそのままクリックできます。

### 会議室での会議

テーブルを囲む会議では、メニューバーのパネルかメモのウィンドウで **マイクをオン** を押すと、Cicada は Mac のマイクでテーブルの人の声を聞き取り、オンライン会議と同じ字幕、メモ、記録を作ります。Mac の音も引き続き聞いていて、何も流れていなければテーブルの声だけが記録されます。話し返しが翻訳を読み上げる間はマイクが聞かないので、翻訳が別の人の発言として記録されることはありません。起動するたびにマイクはオフに戻ります。

会議室にいる人とオンラインの人が混ざる会議でも同じボタンです。オンラインの人は Mac の音から、テーブルの人はマイクから聞き取り、それぞれの言語で一つの会議記録に残します（macOS 14 と 15 では、マイクが Mac の音の代わりになります）。スピーカーから流れるオンラインの声はマイクにも入るので、Cicada はそれが届いているかを測ります。届いていればオンラインの人が話す間だけマイクを止め、ヘッドホンや会議用マイクのときは止めずに、同時に話しても両方残します。Mac で音楽が流れているときも止めません。最後に文字を比べ、Mac の音で直前に流れた発言とほぼ同じ会議室の行は二重に記録しません。

こうした会議では、各行に「会議室」か「オンライン」かが付きます。会議の途中で外付けマイクが抜けたら、残っているマイクに切り替えてお知らせします。マイクがずっと無音なら一度開き直し、それでもだめならメモのウィンドウで変更を促します。Windows と Linux にも同じ **マイクをオン** と同じ仕組みがあります。

### 相手の言語で話し返す

右の `⌥` キーを押したまま話すと、BlackHole 2ch を通じて、翻訳された声が相手に届きます。BlackHole 2ch はアプリからワンクリックでインストールできる仮想マイクで、通訳がオンの間は Cicada が自動的に切り替えます。AI サービスのキーがあれば、相手には自然な音声（OpenRouter と ZenMux では Gemini、Ling では Ming）が聞こえ、Ling では 8〜30 秒のサンプルからあなた自身の声のクローンを作ることもできます。キーがない場合は、macOS のシステム音声を使います。

### 会議の記録

各セッションの二か国語の書き起こし、メモ、録音は Mac に保存されます。会議のあとは記録の中で録音を再生でき、行の時刻をクリックするとそこから再生され、再生中の行が強調されます。話者識別が相手側の声を分離し、Ling のキーが設定されていれば名前も補います。間違っていたら、ライブ議事メモのウィンドウでそのまま名前を変えたり、話者をまとめたり、段落を別の人に割り当て直したりできます。通話が切れたとき、または 10 分間無音が続いたときに、Cicada はセッションを終了して末尾の無音部分を削除します。メモをあとから生成したり、Markdown、Word、SRT の字幕にエクスポートしたりすることもできます。手元の録音や動画を記録のウィンドウにドロップする（または **ファイル › 録音・動画を読み込む…**）と、Mac の中で実時間よりずっと速く書き起こされ、二か国語の記録になります。行の時刻をクリックすると、元のファイルをその位置から再生します。現在、書き起こしの「あなた」に含まれるのは、話すキーを押している間に話した内容だけです。会議に向かって直接話した内容を記録する機能は[ロードマップ](#ロードマップ)にあります。

## プライバシーと権限

Mac では、音声の取得、言語の検出、音声認識（Apple SpeechAnalyzer。macOS 14.4〜15 ではオンデバイスモードの SFSpeechRecognizer）、会議の録音は、すべてパソコンの中にとどまります。デバイスの外に出るデータは、翻訳と議事メモのために送信される認識済みのテキストと、Ling の API キーを使っている場合に話すキーを押しながら話した短い音声クリップだけです。音声モデルのダウンロードが遅いときに「先に Ling で聞く」を選んだ場合は、モデルが入るまでの会議の音声も Ling で認識されます。「設定 › AI サービス」で音声認識を「自分のサービス」にした場合は、会議の音声がそのマシンに送られます。API キーがなくても、字幕、翻訳（Google を使い、macOS 26 では Apple のデバイス上の翻訳にフォールバック）、会議の記録、プッシュトゥトークの通訳はすべて使えます。リアルタイムの議事メモには、OpenRouter（推奨）または Ling（Ant Group のモデルサービス）のあなた自身の AI サービスのキーを使います（[下記](#ling-api-key)を参照）。ワンステップの音声翻訳と声のクローンは Ling のみです。Ling では、リアルタイムのメモ 1 時間あたりの費用は現在の料金で約 ¥0.15〜¥1 で、毎月 ¥10 分のクレジットがもらえるため、約 10〜50 時間分の会議に足ります。

Windows、Linux、Android 版はクラウドで音声を認識します。話された内容は短く区切って Ling の Ming（または切り替えた OpenRouter、ZenMux などのサービス）に送られるため、AI サービスのキーが必要です。録音と会議の記録は、これらのプラットフォームでもデバイスの中にとどまります。

このセクションの残りは Mac 版についての説明です。Cicada が権限を求めるのは、それを必要とする機能を使うときだけで、拒否してもそれ以外の機能は引き続き動作します。

| 権限 | 用途 | 求められるタイミング | ない場合 |
|---|---|---|---|
| システム音声の録音（画面とシステムオーディオの録音） | 字幕のために、Mac で再生されている音を聞き取ります。画面や自身の音を録音することはありません | オンボーディングのステップ 1、または初めて聞き取るとき | 字幕もメモも使えません |
| マイク | 話し返しのために、話すキーを押している間のあなたの声。**マイクをオン** にしたときは、その場にいる人の声 | 話し返しをオンにしたとき、または初めてマイクをオンにしたとき | 話し返しも会議室の聞き取りも使えません |
| 入力監視 | 右の `⌥` が単独で押されたかどうかを判別するためだけに使います（聞き取りのみで、何もブロックしたり記録したりしません） | 初めて右の `⌥` で話すとき | 代わりに設定で `⌃`/`⌘` の組み合わせを選んでください。権限は不要です |
| 管理者パスワード | BlackHole 2ch の仮想マイクのインストールと、システムのオーディオサービスの再起動 | オンボーディングまたは設定でインストールをクリックしたときに 1 回 | 相手に翻訳が聞こえません。それ以外はすべて動作します |

- **ネットワークと仮想マイク**。Cicada が接続するのは、Google 翻訳（`translate.googleapis.com`）、キーを設定した場合の Ling / Ming（`api.ant-ling.com`）または選んだほかの AI サービス、BlackHole の公式のダウンロード、そして 1 日 1 回のアップデートの確認のための GitHub だけです。BlackHole は Apple の公証を受けた公式のパッケージからダウンロードされ、インストール前に、コードに直接書き込まれた SHA-256 のチェックサムと照合されます。
- **アナリティクスも独自のサーバーもなし**。アナリティクス、トラッキング、バックエンドのサーバーは一切ありません。診断情報は、タイミングと回数だけを会議のフォルダーにローカルで記録します。
- **ローカルのストレージ**。会議、録音、メモは `~/Library/Application Support/LiveSubs` に保存されます。Ling のキーと声のサンプルは、あなたのユーザーアカウントだけが読み取れ、Time Machine のバックアップから除外され、ログやエクスポートに書き込まれることはありません。
- **非公開のメモのウィンドウ**。画面共有、画面収録、スクリーンショットには表示されません。ただし、デモを録画するために **画面共有で相手にも見せる** をオンにした場合は除きます。

## モデル

キーがない場合は、すべて Apple のデバイス上のモデルと Google 翻訳で動作します。Ling のキーがある場合は、以下のタスクを Ling と Ming のモデルが担い、リクエストが失敗すると自動的にフォールバックします。OpenRouter、ZenMux、OpenAI では、翻訳とメモは選んだサービスのモデルが Ling の代わりを務め、通訳は Mac の中であなたの声を認識します。話している途中の文はいつも Google 翻訳を使います。自分のサービス（その他（OpenAI 互換））では、「設定 › AI サービス」で「音声とテキストを自分のサービスにのみ送信」をオンにすると、音声もテキストも Google を経由しません。

| 機能 | Ling のキーあり | キーなし / フォールバック |
|---|---|---|
| 音声認識と言語の検出 | Apple `SpeechAnalyzer` / `SpeechTranscriber`（デバイス上）。macOS 14.4〜15：`SFSpeechRecognizer`（デバイス上、音声入力が必要） | 同じ |
| 言い終えた文の翻訳 | Ling `Ling-3.1-flash`（または **設定 › AI サービス** で設定する `Ling-3.0-flash`） | Google 翻訳 → Apple `Translation`（デバイス上、macOS 26 のみ） |
| まだ話している途中の文の翻訳 | Google 翻訳（Ling のレート制限を節約。自分のサービスではオフにできます） | なし：文が終わって翻訳されるまで原文を表示。Google につながらないときは 1 分休止 |
| リアルタイムのメモと最終版 | Ling `Ling-3.1-flash`（同じ設定） | 利用できません |
| キーの確認 | Ling `Ling-3.0-tiny`（1 トークン） | — |
| 通訳：あなたの話を聞き取って翻訳 | Ming `Ming-3.0-audio-flash`（ワンステップ） | Apple のデバイス上の書き起こしのあと、上記の翻訳の流れ |
| 通訳：相手に聞こえる声、声のクローン | Ming `Ming-3.0-tts-0.5B` | macOS のシステム音声（`AVSpeechSynthesizer`）。クローンはなし |
| 話者識別（デフォルトでオン） | 同梱された WeSpeaker ResNet34-LM の声紋、デバイス上（Core ML） | 同じ |

## AI サービスのキーの設定

どちらのサービスでも使えますので、登録できる方を選んでください。**OpenRouter**（推奨）では、同じ Ling のテキストモデルと自然な Gemini の音声が使えます。

1. [OpenRouter](https://openrouter.ai/settings/keys) でキーを作成します。
2. Cicada で **設定 › AI サービス** を開き、右上のメニューで **OpenRouter** を選んでキーを貼り付け、**保存して確認** をクリックします（初回起動時のガイドでは **Ling が使えませんか？** をクリックします）。
3. モデルは品質と価格を考えてあらかじめ選ばれていますが、同じページで自由に変更できます。

ZenMux、OpenAI、または OpenAI 互換の任意のサービス（たとえば Mac 上で動かしているモデル）のアドレスも、同じメニューから同じように使え、ZenMux には Gemini の音声もあります。ライブ議事メモと文の翻訳はどのサービスでも使えます。ワンステップの音声翻訳と声のクローンは Ling のみで、ほかのサービスでは、Apple シリコンの Mac で通訳は端末内で認識してから翻訳します（Intel 版は聞き取りも通訳も Ling が必要です）。キーはサービスごとに保存されるので、元に戻すときに入力し直す必要はありません。自分で動かすモデル（Ollama、vLLM、SGLang など）は用途ごとに設定でき、翻訳とメモ、通訳の音声、音声認識をそれぞれ別のマシンにでき、ローカルネットワークのアドレスは http も使えます。チェックでは実際に 1 文を翻訳し、モデルが先に考える場合や遅すぎる場合ははっきり知らせます（Qwen3 のようなモデルには考えないよう頼みます）。Mac の音声認識は自分の Qwen3-ASR や Whisper などに任せることもできます（既定は Mac のままで、接続できないときは自動で戻ります）。Windows・Linux・Android では聞き取りモデルに別のアドレスを設定できます。接続できないときや key・モデルに問題があるときは、設定画面がどの段階で止まったかと直し方を順に示します。プロキシがオフなのか、プロキシアプリがシステムプロキシになっていないのか、プロキシがオンでも接続できないのかも区別します（Cicada がプロキシ設定を変えることはありません。[セットアップページ](https://cicada.indaloop.app/ja/start/#proxy)を参照）。OpenRouter では残高が少なくなると事前に知らせます。

**Ling**（Ant Group のモデルサービス）では自分自身の声を含むすべての機能が使え、毎月 ¥10 分のクレジットがもらえます：

1. [Ling オープンプラットフォーム](https://chat.ant-ling.com/platform/api)でサインアップまたはログインします。
2. **创建令牌**（トークンの作成）をクリックし、`sk-` で始まるキーをコピーします。
3. Cicada で **設定 › AI サービス** を開き、キーを貼り付けて **保存して確認** をクリックします（またはメモのウィンドウの上部にあるプロンプトに貼り付けます）。1 トークンのリクエストで動作を確認します。
4. 必要に応じて、同じページでモデル（デフォルトは `Ling-3.1-flash`）を、**設定 › 同時通訳** で言語ごとの Ming の音声を選びます。キーを削除するには、同じページで **削除** をクリックします。

## 動作環境とインストール

### Mac

**Apple シリコンまたは Intel** を搭載した **macOS 14.4 以降** が必要です。Apple シリコンの Mac では、macOS 26 はより正確な新しいデバイス上の音声認識を使います。14.4〜15 ではシステムの以前の音声認識を使うため、**システム設定 › キーボード** で **音声入力** をオンにし、聞き取りたい言語をその言語に追加しておく必要があります。Intel 版の Mac ではクラウドの Ming モデルで音声を認識するため、Ling のキーが必要です。UI は英語、中国語、日本語、韓国語に対応しており、macOS の言語に従うか、**システム設定 › 一般 › 言語と地域** でアプリごとに設定できます。

[Releases](https://github.com/wquguru/cicada/releases/latest) または[Web サイト](https://cicada.indaloop.app/ja/)から `Cicada-<version>-macOS-AppleSilicon.dmg`（Apple シリコン）または `Cicada-<version>-macOS-Intel.dmg`（Intel）をダウンロードして開き、**Cicada** を **アプリケーション** にドラッグしてください。ビルドはアドホック署名で、まだ公証されていないため（[ロードマップ](#ロードマップ)を参照）、初回の起動を macOS がブロックした場合は、**システム設定 › プライバシーとセキュリティ** を開いて **このまま開く** をクリックしてください。各リリースには `checksums.txt` が含まれており、`shasum -a 256 Cicada-*.dmg` で検証できます。質問があれば、X で作者の [@wquguru](https://x.com/wquguru) にご連絡ください。

初回起動時のガイドでは、1 つの権限を求めたあと、すぐにリアルタイムの字幕を確認できるよう 2 人の短いサンプルの会議を再生し、AI サービスのキーの接続（またはひとまずスキップ）を手伝い、通訳を使いたい場合は仮想マイクをセットアップします。以降のアップデートは、メニューバーのアイコンにオレンジ色の点として表示され、権限を失うことなくワンクリックでインストールできます。

### Windows

**Windows 10 2004** 以降が必要です。Windows 用のインストーラー（ほとんどの PC では x64、Snapdragon のノートパソコンでは ARM64）をダウンロードしてダブルクリックすると、管理者権限なしでインストールされます。インストーラーはまだコード署名されていないため、SmartScreen に止められた場合は **詳細情報 › 実行** をクリックしてください。Cicada を開くと、残りの手順（Ling のキーの接続、テスト音の再生、サンプルの会議の視聴）を一覧にしたメインウィンドウが表示されます。通訳には無料の VB-Cable 仮想マイクが必要で、インストールはガイドが手伝います。新しいバージョンはアプリ内で知らせ、ワンクリックでインストールできます。

### Linux

**Ubuntu 22.04 または 24.04 のデスクトップ**（x86_64 または arm64）が必要です。`Cicada-<version>-Linux.tar.gz` をダウンロードし、ターミナルで `tar xzf Cicada-<version>-Linux.tar.gz && cicada-linux/install.sh` を実行すると、アプリのメニューに Cicada が表示されます。通訳では独自の「Cicada Microphone」を作るので、ドライバーのインストールは不要です。Linux ではウィンドウを画面共有から隠せないため、共有中はメモのウィンドウに相手から見えている旨が常に表示されます。会議の録音には AAC エンコーダーが必要ですが、Ubuntu には標準で入っていません。サードパーティのメディア形式（`ubuntu-restricted-extras` など）を入れると「設定 › 一般 › 会議の音声を保存」をオンにでき、録音は会議記録で再生でき、各行の時刻からも再生できます。入れていない場合はこのスイッチが灰色になり、ほかの機能はそのまま使えます。

### Android

**Android 10** 以降が必要です。スマートフォンで `Cicada-<version>-Android.apk` をダウンロードして開き、求められたら不明なアプリのインストールを許可してください。Android 15 以降では、初めてフローティング字幕をオンにするときに、アプリ情報で制限付き設定も許可します。通話や会議のアプリは、ほかのアプリにその音声を録音させません。その場合は通話をスピーカーにして **対面** に切り替えてください。

どのプラットフォームのファイルも、Releases ページの `checksums.txt` で検証できます。

## ロードマップ

おおよその優先順です。必要なものは Issues で教えてください。

- **自分の発言の記録**：会議中にエコーキャンセルを使ってマイクの音を聞き取り、自分自身の提案や ToDo も書き起こしとメモに含めます。
- **Developer ID による署名と公証**：初回起動時の「このまま開く」の確認をなくし、AI のキーを macOS のキーチェーンに保存します。Windows のインストーラーにもコード署名を行います。
- **話者の認識**：現在の話者識別をもとに、よく会議に参加する人を Mac 上で声によって覚え、次の会議でも名前が表示されるようにします。
- **API キーなしのローカルのメモ**：対応する Mac では Apple のデバイス上のモデルを使います。
- **Android をアプリストアで配信**：APK をブラウザーからダウンロードする必要をなくします。
- **iPhone と iPad**：iOS ではほかのアプリの音声を取得できないため、会議室の聞き取り、対面での通訳、会議の記録から始めます。

各項目の詳細とトレードオフについては、[docs/ROADMAP.md](docs/ROADMAP.md) をご覧ください。

## アンインストール

Cicada を終了し、**アプリケーション** からゴミ箱にドラッグします。保存されたすべての書き起こし、メモ、録音を削除するには、`~/Library/Application Support/LiveSubs` を削除してください。設定を消去するには、次を実行します：

```bash
defaults delete com.wquguru.cicada
```

## 開発

Mac 版をソースからビルドするには、Xcode Command Line Tools（`xcode-select --install`）が必要です。Cicada にはサードパーティの依存関係がなく、macOS のシステムフレームワークに対して直接ビルドされます。macOS 27 で `SwiftUIMacros` が見つからずにビルドが失敗する場合、その Command Line Tools には SwiftUI のマクロプラグインが含まれていません。Xcode をインストールし、`sudo xcode-select -s /Applications/Xcode.app` を実行してください。Windows、Linux、Android については [windows/README.md](windows/README.md)、[linux/README.md](linux/README.md)、[android/README.md](android/README.md) をご覧ください。

```bash
scripts/build.sh            # dev build → build/Cicada.app ("Cicada Dev", runs beside the installed app)
open build/Cicada.app
scripts/package.sh          # release DMG + zip + checksums
```

アーキテクチャの詳細とリリースのワークフローについては [AGENTS.md](AGENTS.md) をご覧ください。Web サイトのソースは `site/` にあり、`scripts/site.py` で生成されます。リリースの履歴は [CHANGELOG.md](CHANGELOG.md) と、Web サイトの [cicada.indaloop.app/changelog](https://cicada.indaloop.app/changelog/) にあります。
